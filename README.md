# 🏦 DigiBank - Sistema Bancário em Python

Este é um projeto prático desenvolvido em **Python** focado em aplicar os fundamentos da lógica de programação e estruturas de dados dinâmicas. O sistema simula de forma interativa as operações de um banco digital via terminal.

## 🚀 Funcionalidades

- **Abertura de Conta:** Permite cadastrar novos clientes pelo nome com saldo inicial zerado.
- **Depósitos:** Realiza depósitos com validação de valores mínimos e atualização de saldo em tempo real.
- **Saques:** Sistema de saque seguro com dupla validação (verifica se o valor é positivo e se o cliente possui saldo suficiente).
- **Consulta de Saldo:** Busca o cliente na base de dados e exibe o saldo atualizado.
- **Menu Dinâmico:** Interface via terminal baseada em loop interativo para navegação contínua do usuário.

## 💻 Conceitos Aplicados

- **Funções (`def`):** Modularização do código para reaproveitamento e organização da lógica.
- **Estruturas de Dados:** Uso de listas e dicionários para simular uma base de dados de clientes em memória.
- **Estruturas de Repetição e Condicionais:** Controle do menu via `while` e validações de segurança com `if / elif / else`.
- **Interação com o Usuário:** Captura e tratamento de dados inseridos via terminal (`input`).

## 🛠️ Como rodar o projeto

1. Certifique-se de ter o Python instalado na sua máquina.
2. Baixe o arquivo do código ou clone o repositório.
3. Execute o script através do terminal:
```bash
python main.py
```
